# PAFCCI — Predictive Analytics Framework for Cybercrime Complaint Intelligence
## Phase 0: Synthetic Complaint Live Generator

> **IMPORTANT**: All data generated by this system is SYNTHETIC.  
> It must not be used as legal evidence in any court proceeding.

---

## What This Does

This is a **CrewAI-based synthetic data generator** that simulates realistic cybercrime attacker behaviour for training predictive analytics models. It produces structured SMS-style alert prompts that a downstream **Risk Management Agent** can consume.

### 5 CrewAI Agents (Sequential Pipeline)

```
[1] AttackerProfileAgent  ?  Generates attacker profiles (SIM churn, IP rotation)
        ?
[2] TransactionSimAgent   ?  Simulates victim?attacker UPI/IMPS transactions
        ?
[3] MuleChainAgent        ?  Builds N-hop money layering through mule accounts
        ?
[4] ATMWithdrawalAgent    ?  Selects from 200 fixed synthetic ATMs, computes timing
        ?
[5] AlertFormatterAgent   ?  Risk-scores event, formats SMS prompt for next agent
```

## Quick Start

### 1. Clone / Open the project
```bash
cd "d:\MineSafe Stimulation\Withdraw_Predict"
```

### 2. Create virtual environment
```bash
python -m venv .venv
.venv\Scripts\activate      # Windows
```

### 3. Install dependencies
```bash
pip install -r requirements.txt
```

### 4. Configure API key
```bash
copy .env.example .env
# Edit .env and set GOOGLE_API_KEY=your_key_here
# Get free key: https://aistudio.google.com/app/apikey
```

### 5. Run the Streamlit UI
```bash
streamlit run app.py
```
Open http://localhost:8501 in your browser.

### 6. Use programmatically (inside another CrewAI crew)
```python
from generator.crew import CybercrimeGeneratorCrew, make_generator_crew
from generator.config import GeneratorConfig

# Option A: High-level wrapper
crew = CybercrimeGeneratorCrew()
events = crew.run_cycle(GeneratorConfig(num_attackers_active=10))
for ev in events:
    print(ev["sms_prompt"])

# Option B: Raw CrewAI crew (for embedding in parent workflow)
generator_crew = make_generator_crew()
result = generator_crew.kickoff()
```

## Generator Input Parameters

| Parameter | Range | Default | Description |
|---|---|---|---|
| `num_attackers_active` | 1–20 | 5 | Concurrent attacker simulations |
| `phone_churn_rate` | 0.0–1.0 | 0.3 | Probability of SIM swap per cycle |
| `ip_churn_rate` | 0.0–1.0 | 0.4 | Probability of VPN/IP change |
| `transaction_amount_mean_inr` | 1,000–5,00,000 | 45,000 | Mean fraud amount |
| `transaction_amount_variance` | 0.05–1.0 | 0.30 | Amount std-dev as fraction |
| `frequency_before_atm` | 1–20 | 5 | Transactions before withdrawal |
| `mule_chain_depth` | 2–7 | 3 | Hop count in money layering |
| `atm_location_bias` | Urban/Semi-Urban/Rural/Random | Urban | City tier preference |
| `time_report_to_withdrawal_min` | 1–60 min | 15 | Min lag: report ? ATM |
| `time_report_to_withdrawal_max` | 10–240 min | 90 | Max lag: report ? ATM |
| `time_between_prompts_sec` | 10–300 s | 30 | Cycle tick interval |

## Docker

### Build the image
```bash
docker build -t cyberanalyser .
```

### Run both apps
```bash
# Requires a .env file with GOOGLE_API_KEY set
docker run -p 8501:8501 -p 8502:8502 --env-file .env cyberanalyser
```

| App | URL |
|---|---|
| Main Dashboard (`app.py`) | http://localhost:8501 |
| Authority Portal (`portal_app.py`) | http://localhost:8502 |

### Docker Compose (optional convenience)
Create a `docker-compose.yml` alongside the `Dockerfile`:
```yaml
version: "3.9"
services:
  cyberanalyser:
    build: .
    ports:
      - "8501:8501"
      - "8502:8502"
    env_file:
      - .env
    restart: unless-stopped
```
Then:
```bash
docker compose up --build
```

> **Note:** The `.env` file is excluded from the Docker image via `.dockerignore`.  
> Never commit `.env` to version control.
